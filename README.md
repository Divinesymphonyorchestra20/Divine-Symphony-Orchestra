# Divine Symphony Orchestra website

First homepage template based on the DSO Phase 1 website planning document.

## Preview
GitHub Pages can serve this site from the repository root once Pages is enabled.

## Files
- `index.html` — responsive homepage and navigation
- `styles.css` — visual system and mobile styling
- `assets/dso-logo.png` — official DSO logo asset (to be added)

## Project facts and editorial safeguards
- Founding date: **6 March 2007**
- The Orchestra began with seven founding members; names and profiles await verified details.
- DSO's relationship with Mountain of Fire and Miracles Ministries is described without merging the two organisations' marks.
- Our Heritage, Our Legacy and Meet the Members are distinct content areas.
- Founder identities, member profiles, current leadership, event listings, contact details and media remain placeholders until approved source material is supplied.
- Do not publish photographs, recordings or personal details without the required permissions.
